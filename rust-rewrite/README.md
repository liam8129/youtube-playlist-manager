ypm is going to be rewritten from the ground up in Rust for faster speeds, and to make it easier to implement future features. The idea is ypm v2 will be a background application, it will have all current capabilities, but improved as they are in taken in consideration during the rewrite, and new features like occasionally checking, pulling, and downloading playlists automatically so the user doesnt even have to manually use ypm tooling. 

A few other things will be implemented, complicated or not, during the readme:
- Remove gitignore files in folders that should be created upon running: data, logs, oauth-clients, playlist-downloads, playlists
- Simple GUI option (makes it easier for less technical users to control settings and use tooling)
